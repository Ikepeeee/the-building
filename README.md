# The Building

ブラウザで遊べるビル経営シミュレーションです。1Fのロビーから始めて、オフィス・マンション・ホテル・お店を建て、エレベーターで人の流れをさばきながら 100F の超高層タワーを目指します。

- インストール不要。PC（マウス・キーボード）とスマホ・タブレット（タッチ、縦横どちらでも）で遊べます。
- 進行はブラウザに自動で保存されます。
- 絵と効果音はすべてプログラムで生成しているため、画像ファイルや音声ファイルは使っていません。

> **注記**: 本作は 1990 年代のビル経営シミュレーションゲームに影響を受けたファンメイドのオリジナル作品です。既存のゲーム会社・作品とは関係なく、名称・ロゴ・画像・音楽も使っていません。

## 遊び方

1. タイトルで「新しく建てる」を押します。画面の「📋 次にやること」に、やることが順番に表示され、できたものには自動でチェックが付きます（✕で隠せます。メニューから再表示）。
2. ツールバーの「基本」→「ロビー」を選び、1F に横長にドラッグして置きます（人の出入口）。
3. 「フロア」で上の階を作り、「移動」→「エレベーター」を縦にドラッグして各階をつなぎます。
4. 「オフィス」「マンション」などを置くと入居者が来て、賃料や販売収入が入ります。
5. 人口が増えると★が上がり、ホテル・レストラン・映画館などが建てられるようになります。
6. ★5 になったら 100F に大聖堂を建てましょう。結婚式が無事に挙がれば最高ランク **TOWER** 達成です。

### コツ

- エレベーターの待ち時間が長いと、人のストレスが上がります（人の色が黒→ピンク→赤）。評価が悪い状態が続くとテナントが出ていきます。混んできたらエレベーターを選んで「カゴを増やす」か、階段・エスカレーターを足しましょう。
- ホテルの客室はハウスキーピングが清掃しないと次の客が入りません。放っておくとゴキブリが出ます。
- 警備室があると、爆破予告や火事のときに助かります。
- マンションやホテルの近く（同じ階）に飲食店や映画館を置くと、うるさいと苦情が出ます。
- HUD の★か資金を押すと、次の★への条件と今日・昨日の収支が見られます。

## 操作方法

### パソコン

| 操作 | 内容 |
|---|---|
| 左クリック／ドラッグ | 建設（フロア・ロビー・撤去は横に、エレベーターは縦にドラッグ）。クリックした位置が施設の中心になります。施設を含む撤去は確認が出ます |
| 右・中ボタンでドラッグ／Space＋ドラッグ | スクロール（「調べる」のときは左ドラッグでもスクロール） |
| ホイール（Shift で横） | スクロール |
| Ctrl＋ホイール／トラックパッドのピンチ／`+` `-` | ズーム |
| 矢印キー／WASD | スクロール |
| Space | 一時停止／再開 |
| `0`〜`4` | 速度（停止・1・2・4・8倍） |
| Esc／`I` | 「調べる」に戻る・パネルやダイアログを閉じる |
| `F` `L` `E` `X` `T` | フロア・ロビー・エレベーター・急行エレベーター・階段 |
| `O` `C` `H` `R` `B` | オフィス・マンション・シングルルーム・レストラン・撤去 |
| Home／`M`／Ctrl+S | 1F 付近へ戻る／効果音の切り替え／セーブ |

### スマホ・タブレット

| 操作 | 内容 |
|---|---|
| 1本指でドラッグ | スクロール（フロア・ロビー・撤去・エレベーターを選んでいるときは配置） |
| 2本指 | ピンチでズーム、ドラッグでスクロール |
| タップ | 施設を調べる／施設を仮置き（指の位置が中心） → 同じ場所をもう一度タップするか「✓ 建設」で確定 |
| 下のツールバー | 横にスクロールして施設を選ぶ。同じボタンをもう一度押すと「調べる」に戻る |

横向きにするとツールバーが左の縦列になり、ビルを広く見られます。ホーム画面に追加すると、全画面のアプリのように遊べます。

## セーブ

- ゲーム内の1日ごとと、ページを閉じる・別のタブに切り替えるときに、ブラウザ（localStorage）へ自動で保存されます。直前のセーブはバックアップとして1つ残り、メニューの「バックアップから読み込む」で戻せます。セーブ本体が壊れていた場合は自動でバックアップから読み込みます。ゲーム内でエラーが起きたときは、壊れた状態で上書きしないよう自動保存を止めます。
- メニューから手動セーブ、最後のセーブの読み込み、新しいゲームの開始ができます。
- 「セーブデータの書き出し／読み込み」で JSON ファイルの保存・読み込みや、文字列のコピー＆貼り付けができます。別の端末やブラウザへ移すときに使ってください。
- プライベートモードなどで保存できない環境でも遊べます（その場合は書き出しで保存してください）。

## 自分で動かす

ビルド工程や依存ライブラリはありません。ES Modules を使っているため、`file://` で直接開くのではなく、ローカルの HTTP サーバー経由で開いてください。

```sh
cd the-building
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## GitHub Pages で公開する

1. このフォルダをそのまま GitHub のリポジトリに push します（`index.html` がリポジトリのルートにある状態）。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で「Deploy from a branch」を選び、Branch に `main`、フォルダに `/ (root)` を指定して **Save** します。
4. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。このリンクを貼れば、誰でもすぐに遊べます。

すべて相対パスで読み込んでいるので、サブパス（`/<リポジトリ名>/`）でもそのまま動きます。
