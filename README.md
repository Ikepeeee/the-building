# The Building

ブラウザで遊べるビル経営シミュレーションです。1Fのロビーから始めて、オフィス・マンション・ホテル・お店を建て、エレベーターで人の流れをさばきながら 100F の超高層タワーを目指します。

- インストール不要。PC（マウス・キーボード）とスマホ・タブレット（タッチ、縦横どちらでも）で遊べます。
- 進行はブラウザに自動で保存されます。
- 絵と効果音はすべてプログラムで生成しているため、画像ファイルや音声ファイルは使っていません。

> **注記**: 本作は 1990 年代のビル経営シミュレーションゲームに影響を受けたファンメイドのオリジナル作品です。既存のゲーム会社・作品とは関係なく、名称・ロゴ・画像・音楽も使っていません。

## 遊び方

1. タイトルで「新しく建てる」を押します。画面の「📋 次にやること」に、やることが順番に表示され、できたものには自動でチェックが付きます（✕で隠せます。メニューから再表示）。
2. ツールバーの「基本」→「ロビー」を選び、1F に横長にドラッグして置きます（人の出入口）。
3. 「フロア」で上の階を作り、「移動」→「エレベーター」を縦にドラッグして各階をつなぎます。
4. 「オフィス」「マンション」などを置くと入居者が来て、賃料や販売収入が入ります。
5. 人口が増えると★が上がり、ホテル・レストラン・映画館などが建てられるようになります。
6. ★5 になったら 100F に大聖堂を建てましょう。結婚式が無事に挙がれば最高ランク **TOWER** 達成です。

### 便利な機能

- **全体図**: 画面右下の小さな地図に、横に広いビル全体と今見ている範囲が出ます。タップ・ドラッグでその場所へ移動できます。
- **移動手段は施設と重ねて置けます**（移動手段どうしは不可）。「調べる」「撤去」は移動手段が優先です。
- **エレベーターの伸縮**: エレベーターを選ぶと上下に ▲▼ のつまみが出ます。ドラッグで伸ばしたり縮めたりできます（PC は「調べる」でシャフトの上端・下端を直接ドラッグしても OK）。エレベーターの上には機械室、下にはピットが付きます。
- **エレベーターの設定**: パネルの「⚙ 運転設定」から、カゴの数、高速モーター、ドアの開閉時間、待機中のカゴの置き場所、ラッシュ運転、止まる階（階ごとに切り替え）を変えられます。急行は最初はロビー階と地下だけに止まりますが、ほかの階も止まるようにできます（止まる階は2つ以上）。
- **連絡通路**（「基本」・★2で解放・1マス $3,000）: 横にドラッグして架ける橋です。下に支えが無くても建てられますが、少なくとも片方の端は同じ階の建物（フロア・施設）につないでください。離れた棟どうしや、フロアの切れ目を人が歩いて渡れるようになります。橋の上に施設は置けず、上の階の支えにもなりません。スマホでは、なぞったあと仮置きになり、◀▶▲▼ で調整して ✓ で架けます。
- **ぴったり配置**: オフィスなど幅の決まった施設は、隣の施設や幅の区切りから2マス以内なら自動でぴったり寄せて置かれます（すき間ができにくい）。PC では Shift を押している間は寄せません。
- **評価の内訳**: 施設を選ぶと「評価の内訳」に、エレベーター待ち・移動距離・騒音など評価が良い／悪い理由が出ます。
- **コピー**: ツールバーの「コピー」（`K`）で、範囲をドラッグするか施設をクリック／タップして選びます（選んだ施設には ✔ が付きます）。「貼り付けへ」（PC は Enter）を押すと貼り付けモードになり、コピー元と同じ横位置のまま上下だけ動かせます（PC は Shift、スマホは「↔ 横も動かす」で横にも動かせる）。クリック（スマホは ✓）で、フロア・施設・移動手段をまとめて建てます。全部建てられるときだけ建ちます。施設の無い範囲（フロアだけ）をドラッグしたときは、範囲ごとすぐにコピーします。
- **評価の一括表示**: ツールバーの「評価」（`V`）で、すべての施設の評価を色の網掛けで表示します（良い＝青・普通＝黄・悪い＝赤・空室＝灰）。
- **人のプロフィール**: 「調べる」で人をクリック／タップすると、名前・年齢・勤め先や住まい・いまの行動・ストレス・今日の予定が出ます。「📍 追いかける」でカメラがその人を追います（スクロールすると解除）。
- **ホテルのレビュー**: ホテルの客室を選ぶと、宿泊客のレビュー（★の数と一言コメント）の平均と最新3件が見られます。「すべて見る」で全件。
- **夜の早送り**: 深夜 0〜6 時は、事件が起きていなければ自動で ×4 速くなります（HUD に「🌙 早送り中」）。事件が起きると速度は等速に戻ります。
- **サウンド**: 効果音に加えて、画面に映っているものに合わせた環境音（エレベーターの走行音とチャイム、オフィスのタイピングと電話、飲食店の雑談と調理音、ロビーのざわめき、消防ヘリ）が控えめに鳴ります。メニューの「サウンド設定」で効果音・環境音を別々にオン・オフできます。
- **リアルタイム**: 速度ボタンの「実時間」で、ゲーム内の1分が実際の1分になります（夜の早送りもしません）。選んだ速度はセーブに残ります。
- **性能表示と自動調整**: メニューか F3 で、FPS や処理時間を表示できます。重い状態が続くと描画の解像度を自動で下げ、軽くなると戻します（メニューでオフにできます）。
- **全画面表示**: HUD の ⛶ ボタン、またはメニューから（対応ブラウザのみ）。

### コツ

- エレベーターの待ち時間が長いと、人のストレスが上がります（人の色が黒→ピンク→赤）。評価が悪い状態が続くとテナントが出ていきます。混んできたらエレベーターを選んで「カゴを増やす」か、階段・エスカレーターを足しましょう。
- 建てた施設や移動手段は、すぐには使えません。大きさに応じて工事期間があり、完成すると音が鳴ります。パネルに「🚧 工事中（残り○時間）」と出ます。
- 「サービス」の**ごみ・リサイクルセンター**は地下2フロア分の施設で、ビル全体のごみをまとめて集めて分別します（どこに置いても全体を受け持ちます）。毎朝 4:30〜5:30 にごみ収集車が来て回収し、袋の数に応じた料金がかかります。センターが無いか溢れていると、ビル全体のテナントの評価が「ごみが溜まっている」で下がり、苦情の原因になります。ごみが溢れていないことは★4の条件でもあります。ビルが大きくなったら増やしましょう。
- **駐車場**（サービス・地下のみ・★2で解放）: ★3以上になると、オフィスやマンションの入居者の一部（スイートは全室）が車を持ちます。必要な台数が駐車場の台数を超えると「駐車場がない」で評価が下がります。パネルで使用台数・不足台数を確認できます。
- ホテルの客室はハウスキーピングが清掃しないと次の客が入りません。放っておくとゴキブリが出ます。
- 警備室があると、爆破予告や火事のときに助かります。
- マンションやホテルの近く（同じ階）に飲食店や映画館を置くと、うるさいと苦情が出ます。
- HUD の★か資金を押すと、次の★への条件と今日・昨日の収支が見られます。

## 操作方法

### パソコン

| 操作 | 内容 |
|---|---|
| 左クリック／ドラッグ | 建設（フロア・ロビー・撤去は横に、エレベーターは縦にドラッグ）。クリックした位置が施設の中心になります。施設を含む撤去は確認が出ます |
| 右・中ボタンでドラッグ／Space＋ドラッグ | スクロール（「調べる」のときは左ドラッグでもスクロール） |
| ホイール（Shift で横） | スクロール |
| Ctrl＋ホイール／トラックパッドのピンチ／`+` `-` | ズーム |
| 矢印キー／WASD | スクロール |
| Space | 一時停止／再開 |
| `0`〜`4` | 速度（停止・1・2・4・8倍） |
| `5`／`` ` `` | リアルタイム（ゲーム内の1分＝実際の1分） |
| F3 | 性能表示（FPS・処理時間・人数など） |
| Esc／`I` | 「調べる」に戻る・パネルやダイアログを閉じる |
| `F` `L` `E` `X` `T` | フロア・ロビー・エレベーター・急行エレベーター・階段 |
| `O` `C` `H` `R` `B` | オフィス・マンション・シングルルーム・レストラン・撤去 |
| `K`／Ctrl+C | コピー（選んだあと Enter で貼り付けへ。貼り付け中は Shift で横にも動かす） |
| `V` | 評価の一括表示 |
| Home／`M`／Ctrl+S | ビルの 1F 付近へ戻る／音のミュート切り替え／セーブ |

### スマホ・タブレット

| 操作 | 内容 |
|---|---|
| 1本指でドラッグ | スクロール（フロア・ロビー・撤去・エレベーターを選んでいるときは配置） |
| 2本指 | ピンチでズーム、ドラッグでスクロール |
| 指を置いて滑らせる（施設を選んでいるとき） | 施設のゴーストが指の少し上に出て、指に合わせて動きます。離すと仮置き。仮置きを掴んでさらに動かせます。「✓ 建設」で確定、「✕」でやめる。仮置きから離れた所のドラッグはスクロール |
| タップ | 施設を調べる／仮置きを動かさずにタップすると確定 |
| 下のツールバー | 横にスクロールして施設を選ぶ。同じボタンをもう一度押すと「調べる」に戻る |
| ▲▼ のつまみ | 選んだエレベーターを伸ばす・縮める |
| コピー | 1本指でなぞって範囲を選ぶ → タップで貼り付け位置 → 「✓ 建設」 |

横向きにするとツールバーが左の縦列になり、ビルを広く見られます（ノッチやホームバーのある機種にも合わせています）。

**全画面で遊ぶ**: Android の Chrome などは HUD の ⛶ ボタンで全画面になります。iPhone の Safari は全画面表示に対応していないため、共有ボタン →「ホーム画面に追加」で追加したアイコンから起動すると、アドレスバーなしの全画面で遊べます（⛶ ボタンかメニューから手順を表示できます）。

## セーブ

- ゲーム内の1日ごとと、ページを閉じる・別のタブに切り替えるときに、ブラウザ（localStorage）へ自動で保存されます。直前のセーブはバックアップとして1つ残り、メニューの「バックアップから読み込む」で戻せます。セーブ本体が壊れていた場合は自動でバックアップから読み込みます。ゲーム内でエラーが起きたときは、壊れた状態で上書きしないよう自動保存を止めます。
- メニューから手動セーブ、最後のセーブの読み込み、新しいゲームの開始ができます。
- 「セーブデータの書き出し／読み込み」で JSON ファイルの保存・読み込みや、文字列のコピー＆貼り付けができます。別の端末やブラウザへ移すときに使ってください。
- プライベートモードなどで保存できない環境でも遊べます（その場合は書き出しで保存してください）。

## 自分で動かす

タスクは [Lask](https://lask-task-runner.github.io/) で定義しています（`main.lask`）。必要なのは Lask と Docker だけで、Node や Python を入れる必要はありません。各コマンドは `lask.lock.json` で固定したコンテナの中で動きます。

```sh
cd the-building
lask sync            # 初回のみ: イメージを取得する
lask run test        # シミュレーションの自動テスト
lask run build       # テストを通してから dist/ に公開用ファイルを組み立てる
lask run serve       # ソースのままローカルで遊ぶ → http://localhost:8000/
lask run preview     # build した dist/ をローカルで確かめる
lask run deploy      # dist/ を gh-pages ブランチに push して公開する
```

ポートは `--port 8080` のように変えられます。各タスクの説明は `lask run <タスク名> --help` で見られます。

ゲーム自体にビルド工程や依存ライブラリはありません。ES Modules を使っているため、`file://` で直接開くのではなく、HTTP サーバー経由で開いてください（`python3 -m http.server 8000` でも動きます）。

## GitHub Pages で公開する

`lask run deploy` は、`dist/` の中身（`index.html`・`manifest.json`・`css/`・`js/` のみ。`dev/`・`tests/`・`docs/` は含めない）を `gh-pages` ブランチに push します。push には手元の git の認証情報を使います。

初回だけ、リポジトリの **Settings → Pages** で **Source** を「Deploy from a branch」、Branch を `gh-pages`、フォルダを `/ (root)` にしてください。1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

すべて相対パスで読み込んでいるので、サブパス（`/<リポジトリ名>/`）でもそのまま動きます。
